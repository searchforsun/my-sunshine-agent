# 财务签批与授权矩阵

> 文档编号：`c50-fin-approval` · 领域：finance · 语料：corpus-50 · 锚点令牌：`C50-005-APPROVAL`

## 1. 目的与适用范围

本制度规定费用与采购类支出的签批层级、金额阈值、系统路由及代签规则，适用于公司预算内各类非薪资支出（含非标采购、目录内采购、费用报销超权限加签）。劳动合同、股权激励、对外投资与并购、金融机构授信等走专项法务与投委会/资金委员会流程，不适用本矩阵。

## 2. 术语

| 术语 | 含义 |
|------|------|
| 非标采购 | 未纳入年度框架协议或集采目录、需一事一议比价或唯一来源说明的采购 |
| 银杏签批 | 非标采购达到金额阈值后的固定三级链路名称 |
| 财务 BP | 嵌入业务单元的财务伙伴，负责预算占用校验与合规初审 |
| 业务负责人 | 费用归属一级组织（中心/事业部）负责人，非项目经理 |

## 3. 核心锚点

非标采购金额 ≥ 8800 元须走「银杏签批」链路：业务负责人 → 财务 BP → CFO。

检索锚点令牌：`C50-005-APPROVAL`（评测与抽检用，不得删改）。

## 4. 授权矩阵明细

### 4.1 标准费用与目录内采购

| 单笔含税金额 | 采购类型 | 最低签批终点 |
|--------------|----------|--------------|
| ≤ 2000 元 | 任意 | 直线经理 |
| 2000–8799 元 | 任意 | 部门负责人 |
| ≥ 8800 元 | 目录内 / 框架叫价 | 部门负责人 → 财务 BP |
| ≥ 8800 元 | 非标 | **银杏签批**：业务负责人 → 财务 BP → CFO |

金额以申请单含税合计为准；外币按提单日公司公布中间价折算人民币后再比阈值。

### 4.2 银杏签批规则

- 触发：采购类型=非标，且含税金额 ≥ 8800 元。
- 顺序固定，禁止跳级、禁止同一自然人兼任两级、禁止把三级并行成「会签一次完成」。
- CFO 出差期间可指定常务副职为「CFO 授权代理人」，须在组织权限中预先配置；代理人签批意见须注明授权期间。
- 比价要求：非标须附不少于两家有效报价或唯一来源技术说明；缺件财务 BP 一律退回。

### 4.3 框架突破

框架供应商订单通常不走银杏；但若突破框架单价、品类或交货地导致实质变为新采购，系统或财务 BP 应改判非标，达到 8800 元即走银杏。

## 5. 流程时效

1. 经办人发起采购/费用申请，选择类型、科目、供应商与附件。
2. 每级签批时限 2 个工作日；超时自动催办，连续两级超时升级督办。
3. 银杏全链路通过后生成订单号或付款申请号，此前禁止对外下单或预付。
4. 驳回后须在原单修改再提，禁止新建同名同金额单据规避审计轨迹。

## 6. 系统操作

- 非标勾选：采购申请 → 采购类型 → 非标；金额 ≥ 8800 自动套用模板 `APPR-GINKGO`。
- 管理员不得私自改路由跳过 CFO；仅审计工单授权下方可纠正错误费用归属。
- 签批意见须写明预算科目与必要性；空意见「同意」可被财务 BP 退回。

## 7. 例外与反拆单

- **紧急安全生产采购**：可先业务负责人口头批准实施，48 小时内补齐银杏全链路；未补齐不得报销或付款。
- **关联交易**：无论金额，须合规官加审后再按矩阵签批。
- **拆单合并**：任意连续 30 日内对同一供应商、同一需求拆分多笔以规避 8800 的，合并计算并追溯补走银杏；情节严重的按违规论处。

## 8. 禁止与处罚

禁止伪造比价、虚假标记「目录内」、越权代签、拆单规避银杏。造成损失的，经办与审批人连带问责，可追究赔偿责任并记入管理档案。

## 9. FAQ

**Q1：非标 8799 元要银杏吗？**  
A：不要。须非标且 ≥ 8800 元才触发。

**Q2：银杏三人顺序是什么？**  
A：业务负责人 → 财务 BP → CFO，不可调换。

**Q3：项目经理能当业务负责人吗？**  
A：不能。须中心/事业部负责人；项目经理可作经办或会签人。

**Q4：目录内 1 万元怎么签？**  
A：部门负责人 → 财务 BP；供应商若不在目录则改非标走银杏。

**Q5：CFO 驳回后能否只改金额再从业务负责人签一次？**  
A：不能。须自业务负责人起重新完整走完三级。
