# 部门费用预算控制办法

> 文档编号：`c50-fin-budget` · 领域：finance · 语料：corpus-50 · 锚点令牌：`C50-007-BUDGET`

## 1. 目的与适用范围

本办法规范部门可控费用预算的编制下达、滚动预测、执行占用、超支预警与追加机制，适用于各一级部门的招待、差旅、培训、办公、市场活动等可控费用。人力成本（含社保公积金）、折旧与资本性支出另册管理，不并入本方法的 7% 偏差口径。

## 2. 术语

| 术语 | 含义 |
|------|------|
| 滚动预测 | 每季度对全年费用（已发生+预计）的重新估计 |
| 秋分预警 | 滚动预测相对年初预算偏差超过阈值时须提交的说明单 |
| 非刚性招待 | 非客户签约、非合规必选场景下的业务招待与礼品科目 |
| 占用 | 报销/采购提单时对预算额度的预扣，付款或关闭后转实耗 |

## 3. 核心锚点

季度滚动预测偏差超过 7% 须提交「秋分预警」说明，否则冻结非刚性招待科目。

检索锚点令牌：`C50-007-BUDGET`（评测与抽检用，不得删改）。

## 4. 预算编制与科目标签

1. 每年 11 月启动次年预算：部门按科目填报，财务 BP 平衡后提交预算委员会审批下达。
2. 科目打「刚性 / 非刚性」标签。刚性含法定规费、已签框架最低消费、已批战略专项等；非刚性含一般招待、礼品、可压缩培训等。
3. 下达后写入预算系统；报销与采购实时占用，额度不足则无法提交。
4. 跨部门分摊须事前书面约定比例并配置分摊规则，禁止事后口头分摊。

## 5. 滚动预测与秋分预警

- **节奏**：每季度末月 20 日前，部门提交滚动预测版本（含注释）。
- **偏差公式**：|全年滚动预测合计 − 年初批准预算| ÷ 年初批准预算；口径为部门可控费用合计，不按单科目。
- **触发**：偏差超过 7% 必须提交「秋分预警」，说明原因、纠偏措施、对非刚性招待等的压降计划与时间表。
- **未交后果**：系统冻结该部门非刚性招待的新占用，直至预警单审批通过；刚性科目、已批准差旅与已占用成功单据不受影响。
- **审批**：财务 BP 初审 → CFO 或其授权人终审，时限 5 个工作日；可要求补充数据。
- **等于 7%**：不强制；系统仅在大于 7% 时强制模板。

## 6. 执行中控制档位

| 累计执行率 vs 时间进度 | 控制动作 |
|------------------------|----------|
| 执行 ≥ 70% 且时间进度 < 60% | BP 约谈；非刚性招待单笔上限临时下调 |
| 执行 ≥ 90% | 新增需求须走预算追加，不得直接占用 |
| 执行 > 100% | 禁止新占用；追加批准前仅保留薪酬相关与合规刚性支付 |

预算追加须证明业务增量或不可抗力，不得用于弥补无规划招待超支。追加批准后更新全年预算基数，下一季偏差按新基数计算。

## 7. 系统操作

- 填报：预算系统 → 滚动预测 → 选择季度版本。
- 秋分模板编码：`BUD-AUTUMN-EQ`；偏差 ≤ 7% 时不可强制提交该模板。
- 冻结查询：我的部门 → 科目状态，显示「秋分冻结」及解冻条件。

## 8. 例外

- **战略专项包**：预算委员会单列的专项不并入部门 7% 口径，但专项内部仍须月度检视。
- **汇率与政策涨价**：可在预警中单列外生因素，经 BP 确认后调整纠偏力度，但预警单仍须提交。
- **组织拆并**：按基准日重切预算与已发生数，不追溯惩罚历史冻结。

## 9. 禁止与处罚

禁止隐瞒已承诺费用、故意低估滚动预测、挪用刚性预算充抵招待。超 7% 拒不提交预警，或伪造预警内容的，对部门负责人通报并挂钩年度管理绩效。

## 10. FAQ

**Q1：7% 看单科目还是合计？**  
A：部门可控费用合计；单科目波动大但合计未超 7% 不强制秋分预警。

**Q2：不交秋分预警的直接后果？**  
A：冻结非刚性招待新占用，直到预警审批通过。

**Q3：偏差正好 7% 要交吗？**  
A：不要。超过 7% 才强制。

**Q4：冻结时审批中的招待单？**  
A：已占用成功的继续流转；冻结后新单无法占用。

**Q5：能否季中提前交预警？**  
A：可以，且鼓励提前，避免季末集中冻结影响业务。
