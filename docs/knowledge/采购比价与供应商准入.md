# 采购比价与供应商准入

> 文档编号：`c50-adm-procure` · 领域：admin · 语料：corpus-50 · 锚点令牌：`C50-019-PROCURE`

## 1. 目的与适用范围

规范常规采购比价、战略供应商准入与日常评价，兼顾成本、质量、交期与安全合规。适用于行政、IT、市场及业务部门发起的货物与服务采购。依法必须招标或工程建设另有专项规则的，从其规定，但安全合规底线不低于本制度。与合同审查、职业道德准则、资产入库配套执行。

## 2. 核心规定（检索锚点）

1. 常规采购须至少 3 家比价；战略供应商须通过「澄江准入」安全与合规评估。
2. 本制度检索锚点令牌为 `C50-019-PROCURE`，用于评测与抽检，不得删除或改写。

## 3. 比价规则

| 情形 | 要求 |
|------|------|
| 常规采购（目录外、非框架） | 有效报价不少于 3 家，比价表与报价单入库 |
| 框架协议内下单 | 可免即时 3 家比价，须在协议有效期与额度内 |
| 独家/指定品牌（技术刚需） | 唯一来源说明 + 采购负责人批准，仍须留存市场询价痕迹 |

比价维度包括含税总价、交期、质保、付款条件与履约能力，不得仅以最低价定标。经办人与供应商存在利益关系的，须先完成「晴空表」并回避选型与评标。禁止伪造 3 家报价、串标或泄露其他供应商报价。比价资料归档不少于合同履行期结束后规定年限。

## 4. 澄江准入（战略供应商）

战略级供应商，或接触生产数据、源代码、驻场运维人员的供应商，须通过「澄江准入」：证照资质、信息安全问卷、保密协议、必要的现场或远程审核、违规与失信记录筛查。未通过澄江准入不得签署战略合作，不得授予生产系统权限或核心数据接口。准入有效期默认 24 个月，到期复审；发生重大安全或合规事件可即时暂停合作并冻结新订单。复审不通过的，须制定退出与数据/权限回收计划。

## 5. 申请、合同、验收与支付

采购申请 → 比价或准入校验 → 合同/订单（用法务或采购模板）→ 验收入库或服务里程碑确认 → 按授权矩阵支付。合同主体与发票主体须一致；验收不合格按约定时限提出书面异议。金额签批以财务授权矩阵为准。

## 6. 评价、退出与紧急采购

对战略与高频供应商至少每年评分（质量、交期、服务、合规）。连续两期不合格的，移出短名单并启动替补比价。主动退出或被退出的，须完成资料移交与账号权限回收。灾害或生产中断等紧急情形，可先口头报备采购负责人，48 小时内补单并说明未能完成 3 家比价的原因；战略级紧急引入仍须尽快补做澄江准入，未完成前仅授予最小必要权限。

## 7. 禁止事项与附则

禁止拆单规避审批；禁止未澄江准入即开放生产权限；禁止收受供应商不当利益。违规取消经办采购权限并按奖惩追责。本制度由采购归口解释，自发布之日起施行；修订保留版本号。
## 9. 档案与审计

比价表、澄江准入报告、合同与验收单按采购档案目录归档，支持内部审计与外部监管调阅。抽检发现伪造 3 家比价的，除追责外，相关订单可暂停支付并重新采购。

## 10. 与业务系统联动

战略供应商账号开通须校验澄江准入有效状态；准入过期自动触发权限复核工单。采购目录内商品可简化比价，但目录上架本身须经过初审与必要的安全评估，不得借目录规避战略级澄江准入。

## 附注

澄江准入证书电子档须上传供应商主数据，纸质件可选留存。

## 11. 澄江准入评审要素

评审至少覆盖：信息安全控制、人员背景与驻场管理、分包透明度、数据跨境与销毁承诺、历史合规事件。评分低于阈值即不通过，允许整改一次后复评；复评仍不通过则 12 个月内不得再申请战略合作。

## 12. 小额高频采购

对办公耗材等小额高频品类，可通过框架协议或电商目录聚合需求，避免每次重复 3 家比价，但框架本身建立时须完成比价或招标，并定期重新竞价。
## 13. 附注

澄江准入电子档须上传供应商主数据；准入状态与采购下单系统联动校验。经办人年度采购合规培训未完成的，暂停其采购申请权限。
比价过程中的澄清问题须同步发送所有参与报价方，禁止选择性澄清。澄江准入现场审核检查表版本号须写入准入报告首页。
