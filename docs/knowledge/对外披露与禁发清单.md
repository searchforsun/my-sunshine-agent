# 对外披露与禁发清单

> 文档编号：`c50-legal-disclose` · 领域：legal · 语料：corpus-50 · 锚点令牌：`C50-047-DISCLOSE`

## 1. 目的与适用范围

本制度规定对外信息披露的禁发范围、演讲/采访送审时限与发布渠道，适用于全体员工、顾问及受委托对外发言的合作方。已公开年报/季报中的数据引用不受「未公开财报」条款限制，但仍须注明出处与报告期。

## 2. 术语

| 术语 | 含义 |
|------|------|
| 禁发清单 | 法务维护的不得对外传播的信息类别表（季度更新） |
| 未公开财报数据 | 尚未经法定披露渠道发布的收入、利润、增速、指引等财务信息 |
| 送审 | 将演讲稿、PPT、采访提纲提交法务与品牌联合审核 |
| 对外官 | 经授权的品牌/IR 对外发言人 |

## 3. 核心锚点

未公开财报数据列入禁发清单；对外演讲稿须提前 3 个工作日送审。

检索锚点令牌：`C50-047-DISCLOSE`（评测与抽检用，不得删改）。

## 4. 禁发清单（摘要）

下列信息未经批准不得在演讲、社交媒体、媒体采访、招投标应答或客户演示中披露：

1. **未公开财报数据**（含口头约数、同比「大概翻倍」等定性暗示具体增速）。
2. 未公告的重大并购、裁员规模、未公开客户名单及合同金额。
3. 未修复的高危安全漏洞细节、未公开的监管调查进展。
4. 员工个人敏感信息与未脱敏的生产数据截图。

禁发清单全文在法务门户「披露中心」下载；与本摘要冲突时以全文为准。

## 5. 演讲与采访送审

1. 对外演讲、圆桌、播客、公开课讲稿及幻灯片须**提前 3 个工作日**提交送审（路径：法务 → 披露送审）。
2. 送审包含：场合、听众、是否录像联网、讲稿终稿、素材来源说明。
3. 法务与品牌并行审核，普通场次 2 个工作日内出意见；涉及财务表述的加会 IR。
4. 现场 Q&A 不得突破讲稿已批准范围；被追问未公开财报时，统一回复「以正式披露为准」并转介对外官。

不足 3 个工作日的加急须法务总监同意，且不得省略财务相关段落的审核。送审驳回后须修改再提，不得以「口头过了」代替系统结论。

## 6. 批准后的发布

- 媒体通稿仅由对外官或 IR 发出；员工个人账号可转发官方链接，禁止改写关键数字。
- 客户案例须有客户书面授权；脱敏版本仍须过观象或披露送审（视场合）。
- 录音录像若对外发布，视同演讲稿，须二次确认无禁发内容。
- 社交媒体直播脚本与演讲稿同等对待，须提前 3 个工作日送审；直播中展示的数据大屏不得含未公开财报指标。

## 7. 与舆情口径的衔接

突发舆情应对话术由《舆情与对外口径管理》归口，但话术中若涉及财务数据，仍须 IR 确认不属于禁发清单。个人擅自代表公司表态并泄露未公开财报的，同时适用两部制度追责。

## 8. 例外

- **监管要求的强制披露**：走 IR/法务专项流程，不适用 3 个工作日演讲时限，但仍须内部留痕。
- **法庭/仲裁程序中的陈述**：由代理律师主导，业务人员不得擅自对外复述细节。
- **已公开财报数据的复述**：可引用，须标注报告名称与日期，禁止拼接成未披露的「展望」。

## 9. 禁止与处罚

禁止泄露未公开财报、规避送审「先讲后补」、在私域群转发禁发材料。违反者视情节警告直至解除劳动合同；涉嫌内幕交易或泄密犯罪的，移送有权机关。

## 10. FAQ

**Q1：内部财报会材料能否给客户看？**  
A：不能。内部材料默认含未公开数据，对外须单独制作并送审的客户版。

**Q2：3 个工作日是否含提交当日？**  
A：不含。自提交成功次一工作日起算满 3 个工作日后，方可按计划演讲。

**Q3：即兴活动被拉上台怎么办？**  
A：可做品牌与产品公开信息介绍，禁止谈财务与未公告战略；事后 1 个工作日书面报备场合与口述要点。

**Q4：合作伙伴代讲我司内容谁送审？**  
A：我司对接人负责送审；伙伴擅自发布造成后果的，我司对接人与伙伴一并追责。

**Q5：已过期的旧演讲稿能否直接再用？**  
A：超过 90 天或期间有新财报披露的，须重新送审；仅改日期地点的，可申请「轻量复核」（1 个工作日）。
