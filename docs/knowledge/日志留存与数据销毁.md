# 日志留存与数据销毁

> 文档编号：`c50-sec-retain` · 领域：security · 语料：corpus-50 · 锚点令牌：`C50-025-RETAIN`

## 1. 目的与适用范围

本制度规定安全审计日志、关键操作日志与到期业务/归档数据的最短留存期限及销毁控制，适用于平台日志管道、对象存储审计桶、离线介质与云厂商侧归档。业务连续性备份的 RPO/RTO 见灾备制度；本制度侧重合规留存、只追加保护与销毁双人见证。开发联调产生的临时日志不得充当审计证据。

## 2. 基本原则

- **分类留存**：安全审计、业务流水、调试追踪期限不同，禁止混入同一可覆盖滚动桶。
- **不可单人销毁**：销毁须双人在场、书面确认，云上操作亦须双人会话或审批+执行分离。
- **先审后毁**：到期销毁前完成抽样可读性检查与审批，保全锁期间不得销毁。
- **凭证归档**：灰烬单及附件归档不少于 3 年，供内审与监管调取。

## 3. 核心规定（检索锚点）

1. 安全审计日志至少留存 210 天；销毁须双人在场并签署「灰烬单」。
2. 本制度检索锚点令牌为 `C50-025-RETAIN`，用于评测与抽检，不得删除或改写。
3. 涉及个人信息的销毁须同步核对《个人信息保护操作指南》中的法定保留与主体删除请求例外。

## 4. 留存期限一览

| 类别 | 最短留存 | 存放与保护 |
|------|----------|------------|
| 安全审计日志（登录、提权、策略变更、门禁、堡垒机） | **210 天** | 只追加审计桶，开启 WORM/对象锁 |
| 生产变更与发布审计 | 365 天 | 变更平台与星轨归档 |
| 应用调试 / 分布式追踪 | 30 天 | 可滚动删除，禁止写入审计桶 |
| 已脱敏运营分析副本 | 按项目约定，最长 180 天 | 分析隔离区 |

缩短安全审计留存须安全委员会书面批准，且不得低于适用监管强制下限；擅自调低生命周期策略视为高风险事件。

## 5. 销毁流程与「灰烬单」

1. 到期清单由日志或数据 Owner 生成，列明数据集 ID、时间范围、介质/桶位置、预计销毁方式。
2. 安全岗审批通过后预约销毁窗口；涉及客户数据须业务 Owner 会签。
3. **销毁须双人在场并签署「灰烬单」**：一人执行删除、覆写或物理粉碎，一人见证核对对象数量、哈希或介质序列号。
4. 灰烬单必填：数据集 ID、销毁方式（逻辑覆写 / 物理销毁 / 云 API 删除）、时间、双人签名、审批单号、抽检抽样结果摘要。
5. 云资源销毁须保留控制台操作记录或 API 审计 ID，作为灰烬单附件；禁止仅口头确认「已删」。

## 6. 例外、保全与迁移

诉讼保全、监管调取、未结 P0/P1 事故相关日志暂停销毁，标记「保全锁」；解除后重新进入到期队列并重新计算可销毁日。存储迁移时须保持审计链完整，迁移校验报告附于数据集元数据。

## 7. 抽检

安全部每季度抽检不少于 5% 的审计桶与灰烬单：核对是否满足 210 天可检索、双签是否齐全、云审计 ID 是否可回放。抽检失败项须 10 个工作日内整改关闭。

## 8. 禁止事项

禁止单人删除或清空审计桶、用调试日志覆盖审计日志、伪造或补签灰烬单、未审批格式化磁盘、将审计数据导出到个人网盘后「代替留存」。

## 9. 常见问题

- **问：安全审计日志最少留多久？** 答：至少留存 210 天。
- **问：销毁一定要双人吗？** 答：是。销毁须双人在场并签署「灰烬单」。
- **问：调试日志能否当作审计留存？** 答：不能。调试日志滚动删除，不得混入审计桶。

- **问：保全锁多久解除？** 答：保全事由结束后解除，再重新进入到期销毁队列。

## 10. 相关系统与表单

- 系统：审计桶生命周期、WORM/对象锁、堡垒机录像库、灰烬单电子档。
- 表单：到期销毁清单、保全锁申请、灰烬单、抽检整改单。
- 对接：安全委员会缩短留存审批、云厂商删除 API 审计、内审调取接口。迁移存储时须保留审计链校验报告。

## 11. 附则

本制度由信息安全部解释；介质物理销毁外包须使用合格供应商并在灰烬单注明厂商与工单号。灰烬单电子档与纸质（如有）均须可检索；缺失双签的销毁视为无效并需安全部复核。
