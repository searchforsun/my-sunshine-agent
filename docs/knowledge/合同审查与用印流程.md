# 合同审查与用印流程

> 文档编号：`c50-legal-contract` · 领域：legal · 语料：corpus-50 · 锚点令牌：`C50-033-CONTRACT`

## 1. 目的与适用范围

本制度规范合同起草、审查、审批与用印（含电子章），适用于以公司或子公司名义签署的采购、销售、合作、劳动合同补充协议等。员工个人民事协议不适用。与授权矩阵冲突时，金额审批仍走财务签批，文本审查走本制度。

## 2. 术语

| 术语 | 含义 |
|------|------|
| 模板合同 | 法务已发布且未改关键条款的标准文本，版本号可在合同系统查询 |
| 非模板合同 | 对方文本、重大修改模板，或无对应模板的新类型合同 |
| 云玺 | 公司电子签章系统中的法人电子章，仅合同管理员可调用 |
| 关键条款 | 价款、账期、知识产权、保密、违约责任、管辖等不可擅自改动的条款 |

## 3. 核心锚点

非模板合同须法务审核；电子章「云玺」仅授权合同管理员使用。

检索锚点令牌：`C50-033-CONTRACT`（评测与抽检用，不得删改）。

## 4. 审查路径

1. **模板合同**：业务在合同系统选择最新模板，填写变量区；系统自动路由业务负责人审批，法务按比例抽检。
2. **非模板合同**：须提交对方文本或改稿对照，必须经法务审核通过后方可进入用印；金额或风险等级达到矩阵阈值的，加签财务/信息安全。
3. 法务审核时限：普通 5 个工作日，加急（说明上线/投标截止日）3 个工作日；材料不全一次性退回。
4. 多语言文本以中文版为准，外文版须与中文一致或附差异说明；冲突时中文优先，除非合同明示外文为准且经法务确认。
5. 补充协议、解除协议视同新合同审查；若仅变更金额且套用补充模板，可走简化路径但仍须系统留痕。

## 5. 用印规则

- 纸质公章：行政印章岗凭已审批合同系统单用印，骑缝与签字页齐全，用印登记本当日录入。
- 电子章「云玺」：仅授权合同管理员在电子签平台发起；业务经办人不得索要管理员账号，不得借用他人身份调用。
- 用印后须回传签署件扫描件至合同系统，未回传视为流程未闭环，影响后续付款/收票。
- 作废重打须注明原印鉴编号，旧件收回或电子作废标记；丢失公章印模按安保事件上报。

## 6. 角色职责

| 角色 | 职责 |
|------|------|
| 业务经办 | 发起、谈判纪要、跟踪对方盖章 |
| 部门负责人 | 商业条款合理性初审 |
| 法务 | 非模板审核、模板维护、争议条款把关 |
| 合同管理员 | 云玺调用、印鉴台账、签署件归档衔接 |

## 7. 例外

- 框架协议已审、本单仅为订单附件且条款未改：可按模板路径走，但订单金额仍须符合授权矩阵。
- 诉讼/仲裁和解协议：一律视同非模板，须法务与分管领导双审。
- 紧急投标：可法务口头原则同意后用印，须在 2 个工作日内补录审核意见。

## 8. 禁止与处罚

禁止未经法务审核签署非模板合同、私盖实体章、转借云玺权限、倒签且隐瞒。查实后合同效力评估由法务主导，责任人按合规处分处理，造成损失的依法追偿。

## 9. FAQ

**Q1：改了模板里的付款账期算不算非模板？**  
A：算。关键商务与法律条款被改即进入非模板路径，须法务审。

**Q2：云玺电子章谁能用？**  
A：仅授权合同管理员。业务人员在系统提交用印申请，由管理员操作云玺。

**Q3：子公司章是否也叫云玺？**  
A：子公司使用各自电子章名称，本制度「云玺」特指母公司电子章；子公司参照本流程授权本地合同管理员。

**Q4：对方先盖章的 PDF 能否直接云玺？**  
A：可以，但仍须完成对应审查路径；合同管理员核验文本与审批单一致后再盖。

**Q5：入职劳动合同是否走云玺？**  
A：入职劳动合同由 HR 专用电子签处理；商务合同用云玺。以公司名义签署的补充协议按非模板或对应模板路径分流。
## 10. 归档衔接与台账

用印完成后，合同管理员须在 2 个工作日内将签署件推送档案库任务（归档时限见《电子归档与借阅规则》）。云玺调用日志至少保留 3 年，字段含操作人、合同编号、哈希摘要。印章盘点每月一次，实物章与电子章授权名单不一致的，立即冻结差异账号。

## 11. 附则

本制度由法务部解释，自发布之日起施行。模板版本升级时，旧版模板自动停用；在途单据可在 10 个工作日内用旧版完成签署，逾期须切换新版并视同条款变更复审。
