# 前端傻瓜式验收：L1 / L2 / L3

**前提**：不改 Nacos / Catalog 配置。默认近窗 8 轮、中窗 8 轮（一轮 = 你问一句 + AI 答一句）。

**开始前清库（必做）**

```bash
cd /usr/local/gitproj/my-sunshine-agent
python3 scripts/clear_session_cache.py --force
```

浏览器打开 sunshine-ui → F12 控制台粘贴脚本末尾打印的 JS → 回车 → **硬刷新**（Ctrl+Shift+R）。

打开侧栏 **上下文** `/context`，选好与 Chat **同一用户**，后面对照看 L1/L2/L3 页签。

执行模式建议：Chat 底栏选 **ReAct**（或自动即可），**不要**强绑复杂 Workflow。

---

## 一、验 L2（跨会话用户状态）— 约 3 分钟

目标：明确偏好写入 L2，新对话仍能「记得」。

| 步 | 在哪 | 做什么 |
|----|------|--------|
| 1 | Chat | **新建对话**，原样发送下面 **提示词 A** |
| 2 | Chat | 等回答 **完成**（转圈停） |
| 3 | `/context` → L2 | 刷新；应出现类似 `preference` / 语言相关条目，状态 **生效** |
| 4 | Chat | **再新建一个对话**（不要沿用旧会话），原样发 **提示词 B** |
| 5 | Chat | 看回复是否用英文、或明确提到你偏好英文 |

**提示词 A（写入 L2）**

```
请记住我的长期偏好：以后请默认用英文回答我。这是我的明确要求，不是临时一次。
```

**提示词 B（新会话验证注入）**

```
用一句话介绍你自己。
```

**通过标准**

- `/context` L2 有对应 **生效** 条目  
- 新会话回复为英文（或明确按英文偏好作答）

**失败时**

- L2 无条目：等 5～10 秒再刷新；确认选对同一用户  
- 新会话仍中文：看 L2 是否被标成「矛盾/已作废」；有则手动改回「生效」再试提示词 B

## 二、验 L1（同会话近 / 中 / 远）— 约 10 分钟

目标：同一会话里，超过近窗后出现 **中窗摘要**；再往后出现 **远窗**。

| 步 | 在哪 | 做什么 |
|----|------|--------|
| 1 | Chat | **新建对话**（建议另开，避免和 L2 混看） |
| 2 | Chat | **依次**发送下面 **轮次 01～18**（每条发完等完成再发下一条；可复制粘贴） |
| 3 | `/context` → 选该会话 → L1 | 刷新；应看到 **近 / 中 / 远** 分区 |
| 4 | L1 中窗 | 点开中窗卡片：user 为原文，assistant 为**摘要**（不是全文复述） |
| 5 | L1 远窗 | 若有远窗：应是折叠摘要，不是近 8 轮原文 |

**轮次提示词（01～18，请整句发送）**

```
05 我的项目代号是 ALPHA-05，请只回复：已记录 ALPHA-05。
06 我的项目代号是 ALPHA-06，请只回复：已记录 ALPHA-06。
07 我的项目代号是 ALPHA-07，请只回复：已记录 ALPHA-07。
08 我的项目代号是 ALPHA-08，请只回复：已记录 ALPHA-08。
09 我的项目代号是 ALPHA-09，请只回复：已记录 ALPHA-09。
10 我的项目代号是 ALPHA-10，请只回复：已记录 ALPHA-10。
11 我的项目代号是 ALPHA-11，请只回复：已记录 ALPHA-11。

```

发完 18 后，可再发一条确认近窗：

```
请列出你还完整记得的项目代号（尽量按近窗原文）。
```

**通过标准**

- L1 有 **近**（较新轮次原文）  
- 有 **中**（稍早轮次；assistant 为摘要）  
- 通常还有 **远**（更早折叠）；若仅近+中也可接受（取决于压缩时机，可再多发 2～4 轮）

**失败时**

- 只有近、没有中：再发 2～4 轮 `ALPHA-19`… 后刷新 L1  
- 中窗 assistant 仍是长文：等本轮 completed 后再刷新（压缩异步）

## 三、验 L3（跨会话历史细节召回）— 约 5 分钟

目标：旧会话里的**独特细节**，在新会话被当作「历史材料」用上（不是 L2 那种结构化偏好）。

| 步 | 在哪 | 做什么 |
|----|------|--------|
| 1 | Chat | **新建对话 C1**，原样发 **提示词 C**，等完成 |
| 2 | `/context` → L3 | 选会话 C1，刷新；应出现该轮消息的索引卡片（可点「重新会话索引」若为空，再等几秒） |
| 3 | Chat | **再新建对话 C2**（必须新会话），原样发 **提示词 D** |
| 4 | Chat | 看回复是否提到 **「青柠协议」** 或金额 **「328 万」** |

**提示词 C（埋细节，写入 L3）**

```
请记住一个仅用于测试的虚构合同细节（不要写入偏好）：合同昵称是「青柠协议」，签约金额正好是 328 万人民币。请用一两句话确认你已看到这两个细节。
```

**提示词 D（新会话召回）**

```
我之前提过一个测试用的虚构合同，昵称和金额分别是什么？如果记忆里没有就说没有。
```

**通过标准**

- C1 在 `/context` L3 有 chunk  
- C2 回答能说出「青柠协议」和/或「328 万」（允许措辞略有出入）

**失败时**

- L3 列表空：在该会话点 **重新会话索引**，等 10 秒刷新  
- C2 说没有：确认 C1 已 completed；再在 C2 重发提示词 D；或先在 C1 再聊一句短回复触发 ingest

## 四、一分钟总检查表

| 层 | 页面 | 看什么 |
|----|------|--------|
| L2 | `/context` L2 | 有「生效」偏好；新会话行为符合偏好 |
| L1 | `/context` L1 | 同会话出现近 / 中（/ 远）；中窗 assistant 是摘要 |
| L3 | `/context` L3 | 旧会话有索引；新会话能问出旧细节 |
